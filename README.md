# Sila Digital Website

Static website prepared for GitHub Pages.

## Upload to GitHub

1. Open your `sila-digital` repository.
2. Click **Add file** → **Upload files**.
3. Upload the contents of this ZIP (not the outer folder).
4. Click **Commit changes**.
5. Open **Settings** → **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then click **Save**.

Your site should become available at:

https://haesamhassan88-sketch.github.io/sila-digital/

## Important

Before sending the site to a payment provider, review all text and make sure it accurately reflects your real business, prices, service process, and refund practices.
