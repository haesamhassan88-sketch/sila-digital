تم تفعيل الدفع عبر فواتيرك
========================

تم ربط الخدمات الست بروابط الدفع الرسمية التالية داخل payment-config.js:
- خدمات ويندوز
- تجهيز سيرفر ديسكورد
- تصميم شعار احترافي
- التصميم الجرافيكي
- الدعم الفني
- الهوية البصرية

طريقة الشراء:
1) يختار العميل الخدمة من الموقع.
2) يدخل بياناته في صفحة إتمام الطلب.
3) يضغط الدفع الآن.
4) ينتقل إلى صفحة فواتيرك الخاصة بالخدمة لإتمام الدفع.

ملاحظة أمنية: لا تضع مفاتيح API أو بيانات الدخول داخل ملفات GitHub العامة.
