تفعيل الدفع عبر Paymob
======================

الموقع جاهز لاختيار الخدمة وإدخال بيانات العميل والانتقال إلى بوابة الدفع.
لتشغيل زر "الدفع الآن" فعليًا:

1) أنشئ Payment Link منفصل لكل خدمة من لوحة Paymob.
2) افتح ملف payment-config.js.
3) ضع رابط كل خدمة بين علامتي الاقتباس أمام اسمها.
4) ارفع الملف إلى GitHub واضغط Commit changes.

مثال:
windows: "https://accept.paymob.com/standalone/?ref=..."

مهم:
- لا تضع API Key أو أي مفتاح سري داخل ملفات GitHub Pages.
- روابط الدفع العامة من Paymob مناسبة للموقع الثابت.
- بدون روابط Paymob الحقيقية سيعرض الموقع رسالة واضحة بدل إرسال العميل إلى رابط غير صحيح.
